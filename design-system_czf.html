Règles Générales
  • Toujours Barlow Condensed 800 Italic pour les titres et éléments de marque. Jamais de rounding sur les composants UI (border-radius: 0 ou très faible).
  • Tous les éléments interactifs utilisent skewX(-8deg) pour l'effet parallelogramme et box-shadow 6px 6px partout. Hover press : shadow → 2px 2px + translate(4px, 4px).
  • Règle des ombres (sans exception) : fond clair (cream #F4E2C9, beige, blanc, orange) → ombre dark #081428. Fond sombre (dark navy) → ombre orange #F05010.
  • Filtres/Tabs : inactif = fond cream + shadow dark. Actif = fond dark + shadow orange. Les deux en skewX(-8deg).
  • La couleur orange #F05010 est réservée aux accents, CTA et ombres sur fond sombre. Ne pas l'utiliser comme fond de section.
  • La couleur teal #00C9A0 est réservée à la division Ixtal et aux indicateurs positifs. Sur fond dark, le chip Ixtal est dark bg + texte teal.
  • Les séparations entre sections beige et dark utilisent clip-path diagonal dans le même sens que le ticker (haut-droite vers bas-gauche).
  • Le ticker bandeau est toujours incliné skewY(-1deg) avec ombre dark 7px en dessous. Texte uppercase italic, séparateur ⚡.
  • Le fond beige utilise un pattern de 4 gradients diagonaux superposés à angles légèrement différents pour un effet organique subtil.
  • Texte sur fond sombre : #E0D8CC (--on-dark). Jamais de blanc pur #ffffff sur dark, sauf éléments de contraste fort.
  • Score victoires/défaites : vert #2aab5f pour les victoires, rouge #E05050 pour les défaites.
